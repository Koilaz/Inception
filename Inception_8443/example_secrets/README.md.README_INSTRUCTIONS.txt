==============================================================================
INSTRUCTIONS FOR SECRETS
==============================================================================
1. Rename the parent folder from 'example_secrets' to 'secrets'
2. Change the contents of all the .txt files in this folder to your actual passwords/usernames.
3. IMPORTANT: Make sure each .txt file contains ONLY the secret value on a single line with no extra spaces or newlines.
4. Comments are not allowed in these files as they will be read literally by the containers as the password/username.
